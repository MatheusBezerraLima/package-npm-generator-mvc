# package-npm-generator-mvc
Este pacote foi desenvolvido para facilitar a criação e organização da estrutura de pastas no padrão MVC (Model-View-Controller) de forma otimizada e prática em seus projetos. Com um simples comando, você pode gerar automaticamente a arquitetura básica do padrão MVC, economizando tempo e garantindo consistência na estruturação de novos projetos.
